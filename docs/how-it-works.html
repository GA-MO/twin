ภาพนี้จำลองจากการทดสอบจริงวันที่ 28 ต.ค. 2026 แถบที่มีขอบสีรุ้งคือแถบสถานะของ twin เมื่อมีงานรอคุณ ปุ่มจะขึ้นเหนือช่องพิมพ์ กดครั้งเดียวก็อนุมัติได้

วันหนึ่งกับ twin

ตั้งแต่เปิดแอปจนงานเสร็จมีทั้งหมด 7 ขั้น กดแต่ละขั้นเพื่อดูว่าเกิดอะไรขึ้น และดูตัวอย่างจากการทดสอบจริง

    ตัดสินใจแทนได้แค่ไหน

    twin แบ่งงานเป็นหมวด เช่น อนุมัติ release ตอบอีเมลลูกค้า นัดประชุม แต่ละหมวดมีระดับของตัวเอง ทุกหมวดเริ่มที่ "ถามก่อนทุกครั้ง" (เว้นแต่ประวัติที่คุณให้อ่านบอกว่าคุณปล่อยเรื่องนั้นอยู่แล้ว) แล้วค่อยขยับขึ้นเมื่อคุณไว้ใจ คุณขยับขึ้นหรือลงเองได้ทุกเมื่อ

    1. ดูเงียบดูและจดไว้ ยังไม่เสนออะไร
    2. ถามก่อนถามคุณทุกครั้งก่อนทำทุกหมวดเริ่มที่ระดับนี้
    3. ร่างให้เตรียมไว้ให้เสร็จ คุณแค่กดส่ง
    4. ทำแล้วบอกทำเลย แล้วสรุปให้รู้ว่าทำอะไรไป
    5. ทำเงียบทำเองโดยไม่ต้องรายงาน ใช้กับเรื่องเล็กที่คุณไว้ใจเต็มที่

    ตัวอย่างหมวด: อนุมัติ release

    ระดับ: ถามก่อน
    ลูกค้าใหญ่หรือเกี่ยวกับเงินเจ้าของดูเองทุกอย่าง twin เตรียมสรุปให้ตรวจ
    ลูกค้าเล็กQA ผ่านก็ปล่อยได้ twin ร่างข้อความอนุมัติไว้ให้

    กฎนี้ได้มาจากการ onboard ทดสอบ (เล่นเป็นหัวหน้าทีม dev 8 คน) เหตุผลที่จดไว้คือ "ลูกค้าใหญ่เคยโดนปรับเพราะบั๊กหลุด" พอเปิดคุยรอบใหม่ twin ใช้กฎนี้ได้ถูกทั้งสองกรณี และยังถามก่อนเพราะยังไม่ได้รับสิทธิ์

    twin เรียนรู้คุณอย่างไร

    twin ไม่ได้ฉลาดตั้งแต่วันแรก มันเริ่มจากการถาม แล้วรู้จักคุณมากขึ้นทุกวัน สิ่งที่มันเรียนรู้ถูกจดเป็นไฟล์ในเครื่องของคุณ เปิดอ่านและแก้ได้

    1

    ขออนุญาตก่อน

    ถามว่าอ่านประวัติที่คุณเคยคุยกับ Claude ได้ไหม ตอบไม่ก็ได้ ถ้าถอนความยินยอมทีหลัง ข้อมูลที่เก็บไว้จะถูกลบ

    2

    เดาจากประวัติ หรือถามทีละข้อ

    ถ้ามีประวัติเยอะ จะเดากฎแล้วให้คุณตอบว่า ถูก ผิด หรือแล้วแต่ ถ้ามีน้อย จะถามเป็นสถานการณ์จริงครั้งละ 5 ข้อ หยุดได้ทุกเมื่อ

    3

    จดเป็นกฎ

    แต่ละกฎมีเหตุผลและที่มากำกับ แยกไว้ 3 แบบ คือกฎทั่วไป เส้นที่ห้ามข้าม และระดับสิทธิ์ของแต่ละหมวด

    4

    ใช้ในงานจริง

    ทุกครั้งที่เปิดคุย twin โหลดกฎเหล่านี้ก่อนเสมอ จึงตัดสินใจเหมือนเดิมทุกครั้ง

    5

    คุณแก้ มันปรับ

    พิมพ์ "จด feedback: …" เมื่อมันทำไม่ถูกใจ แล้วสั่ง improve เพื่อให้มันปรับวิธีทำงาน

    6

    ถามเพิ่มวันละ 1-3 ข้อ

    มันเลือกถามเรื่องที่ยังรู้จักคุณน้อยที่สุดก่อน

    รู้จักคุณ 6 ด้าน

    twin วัดว่าตัวเองรู้จักคุณแค่ไหนในแต่ละด้าน 0 คือยังไม่รู้ 1 คือเดา 2 คือคุณบอกเอง 3 คือคุณบอกและหลักฐานตรงกัน ตัวเลขด้านล่างมาจากการทดสอบหลังตอบไป 4 ข้อ

    ช่วยงานอะไรได้บ้าง

    พิมพ์ว่าtwin ทำอะไร
    มีอะไรค้างสรุปงานค้าง ประชุม และเรื่องที่ต้องดูวันนี้ โดยเรียงเรื่องสำคัญไว้ก่อน
    จำไว้ว่า… / เตือน…จดเป็นโน้ต แล้วยกขึ้นมาเตือนในสรุปเมื่อถึงกำหนด
    สรุปประชุม แล้ววางโน้ตลงไปแยกเป็นสิ่งที่ตัดสินใจแล้ว งานที่คุณต้องทำ และงานที่ต้องส่งต่อ
    ไปแก้ X ในโปรเจกต์ Yส่งผู้ช่วยไปทำในสำเนาแยกของโปรเจกต์นั้น แล้วรายงานกลับพร้อมปุ่มอนุมัติ
    ถึงไหนแล้วบอกว่าผู้ช่วยแต่ละตัวทำอะไรอยู่ และอะไรรอคุณ
    จด feedback: … / improveปรับตัวตนและวิธีทำงานตามที่คุณแก้
    /twinเปิดแผงข้างแชตที่แสดงทุกงานที่ส่งไป และกดอนุมัติหรือตอบได้จากตรงนั้น

    ข้อมูลของคุณอยู่ที่ไหน

    ตัวตน โน้ต และบันทึกประจำวันของคุณอยู่ในโฟลเดอร์ profile/ notes/ และ journal/ ในเครื่องของคุณ เมื่ออัปเดต twin เวอร์ชันใหม่ ข้อมูลเหล่านี้จะไม่ถูกแตะ และไม่ถูกส่งกลับไปที่ต้นทาง twin สำรองข้อมูลไว้ในเครื่องทุกชั่วโมง ถ้าอยากสำรองไว้นอกเครื่อง ให้สร้าง repo ส่วนตัวไว้หนึ่งที่ แล้ว twin จะส่งสำรองไปที่นั่นเอง

    สิ่งที่ twin ไม่ทำ แม้คุณจะให้สิทธิ์สูงแล้ว

    • ไม่เอางานเข้า branch หลักจนกว่าคุณจะกดอนุมัติงานนั้น และไม่ขึ้นระบบจริง (production) ให้เลย ขั้นนั้นคุณทำเองเท่านั้น
    • ไม่แก้ไฟล์ในโปรเจกต์อื่นเอง ทุกงานทำในสำเนาแยกที่ลบทิ้งได้
    • ไม่เก็บข้อมูลของคุณไว้ที่ไหนนอกเครื่อง นอกจาก repo สำรองที่คุณตั้งเอง (สิ่งที่คุณพิมพ์คุยยังส่งไปที่ Claude ตามปกติ)
    • ไม่เก็บรหัสผ่านหรือ token ลงไฟล์

    ต่อยอดให้ twin ทำอย่างอื่น

    twin ประกอบด้วย 4 ชิ้นที่เพิ่มของใหม่ได้โดยไม่ต้องแก้ส่วนอื่น สั่ง twin ให้เพิ่มเองก็ได้ เช่น "เพิ่มแหล่งข้อมูลจาก Outlook"

    แหล่งข้อมูลใหม่

    เพิ่มไฟล์เดียวในโฟลเดอร์ collectors/ แล้วระบบจะเช็กทุก 10 นาที ดึงข้อมูลตามรอบที่ไฟล์นั้นกำหนด และเอาเข้าสรุปงานเอง

    • อีเมลและปฏิทินจาก Outlook
    • ข้อความจาก Teams หรือ LINE ที่รอคุณตอบ
    • สถานะงานจาก Jira หรือ Trello ของทีม

    ความสามารถใหม่ (skill)

    เพิ่มโฟลเดอร์ที่มีไฟล์คำอธิบายหนึ่งไฟล์ ว่าเมื่อคุณสั่งแบบนี้ ให้ทำขั้นตอนอะไรบ้าง

    • สรุปความคืบหน้าประจำสัปดาห์ส่งลูกค้า
    • เตรียม checklist ก่อนอนุมัติ release
    • แบ่งงานจากอีเมลลูกค้าให้คนในทีม

    แถบสถานะและปุ่ม

    แถบเหนือช่องพิมพ์เป็น mod ที่เพิ่มการ์ดชนิดใหม่และปุ่มใหม่ได้

    • การ์ด "อีเมลด่วนรอตอบ" พร้อมปุ่มร่างคำตอบ
    • ป้าย "nok พร้อม" เมื่อไม่มีงาน ให้รู้ว่าทำงานอยู่

    สิทธิ์ที่โตขึ้นเอง

    ระยะถัดไป twin จะเดาก่อนว่าคุณจะตัดสินใจอย่างไร แล้วนับว่าเดาถูกกี่ครั้ง เมื่อถูกบ่อยพอจะเสนอขยับระดับให้คุณกดยืนยัน

    • ไฟล์สิทธิ์มีช่องนับไว้แล้ว ยังไม่ได้เปิดใช้

    งานที่วางไว้ทำต่อ

    • คำสั่ง doctor ที่เช็กการติดตั้งทุกอย่างในคำสั่งเดียว ใช้เมื่อมีอะไรไม่ทำงาน
    • ใส่ภาพหน้าจอในคู่มือติดตั้ง สำหรับขั้นเลือกโฟลเดอร์และกด Trust workspace
    • ลองบน Windows เครื่องจริง ตอนนี้ทดสอบแล้วบน Mac
