twin เป็นโปรเจกต์โอเพนซอร์สที่เปลี่ยน Claude Code ให้เป็นผู้ช่วยของคุณคนเดียว คุณ clone repo มาไว้ในเครื่อง ตั้งชื่อ agent เอง แล้วคุยกับมันในแท็บ Code ของแอป Claude Desktop หรือในเทอร์มินัล

มันรู้ว่าคุณมีงานอะไรค้าง มีประชุมอะไร ค่อยๆ เรียนรู้ว่าคุณตัดสินใจอย่างไร และขออนุญาตก่อนทำเรื่องที่คุณยังไม่ได้มอบให้ ในคู่มือนี้ใช้ชื่อ agent ตัวอย่างว่า `nok`

## twin ทำอะไร

- **สรุปงานตอนเปิดคุย** ทุกครั้งที่เริ่มคุยใหม่ agent ได้ brief ที่รวมงานค้าง ประชุมที่ใกล้ถึง งานที่ส่งไปทำ และโน้ต เรียงเรื่องสำคัญไว้ก่อน พิมพ์ `มีอะไรค้าง` แล้วมันตอบจาก brief ได้ทันที
- **จดโน้ตและเตือน** พิมพ์ `จำไว้ว่า…` หรือ `เตือนฉันว่า… ภายในวันศุกร์` มันเขียนโน้ตเป็นไฟล์หนึ่งไฟล์ แล้วยกขึ้นมาใน brief เมื่อถึงกำหนด
- **สรุปประชุม** วางโน้ตหรือ transcript ลงไป มันแยกเป็นสิ่งที่ตัดสินใจแล้ว งานของคุณ และงานที่ต้องส่งต่อ
- **ส่งงานไปทำในโปรเจกต์อื่น** พิมพ์ `ไปแก้ X ใน Y` มันส่ง worker ไปทำใน worktree แยกของโปรเจกต์นั้น แล้วรายงานกลับพร้อมปุ่มอนุมัติ งานไม่เข้า branch หลักจนกว่าคุณจะอนุมัติ
- **เรียนรู้คุณ** ครั้งแรกพิมพ์ `onboard` มันเรียนรู้จากประวัติที่คุณยอมให้อ่าน หรือถามเป็นสถานการณ์จริงทีละข้อ เมื่อมันทำไม่ถูกใจ พิมพ์ `จด feedback: …` แล้วสั่ง `improve`

## เหมาะกับใคร

ทุกคนที่ใช้ Claude ได้ รวมถึงคนที่ไม่ได้เขียนโค้ด ติดตั้งครั้งเดียวด้วยคำสั่งไม่กี่บรรทัด จากนั้นคุยเป็นภาษาปกติในแท็บ Code ของ Claude Desktop

คนที่เขียนโค้ดได้ประโยชน์มากกว่า ตั้งโฟลเดอร์ code ไว้ แล้ว agent จะดูทุก repo ในนั้น ส่ง worker ไปแก้งานโดยไม่ชนกับ session ที่คุณเปิดอยู่ และเพิ่มคำสั่ง แหล่งข้อมูล หรือ skill ของคุณเองได้

## ข้อมูลยังเป็นของคุณ

- ไม่มี daemon ไม่มีฐานข้อมูล ไม่มีบริการบน cloud ทุกอย่างเป็นไฟล์ในโฟลเดอร์ของคุณ และ hook กับตารางเวลาของระบบปฏิบัติการเรียกใช้เป็นรอบ
- ตัวตน โน้ต และบันทึกประจำวันอยู่ใน `profile/`, `notes/` และ `journal/` ซึ่งไม่อยู่ใน git เมื่อ `git pull` เวอร์ชันใหม่ ไฟล์เหล่านี้ไม่ถูกแตะ และไม่ถูกส่งกลับไปที่ repo ต้นทาง
- สำรองข้อมูลไปนอกเครื่องได้เฉพาะ repo ส่วนตัวที่คุณตั้งเอง
- API key กับ token เก็บใน secret store ของเครื่อง ไม่เขียนลงไฟล์

สิ่งที่คุณพิมพ์คุยยังส่งไปที่ Claude ตามปกติ
