หน้านี้เล่า run จริงหนึ่งรอบ คุณสั่งแก้บั๊กใน repo ตัวอย่าง `files-admin` ด้วยประโยคเดียว แล้วปิดงานเมื่อเสร็จ ทุกฉากเริ่มจากแชทที่คุณเห็น แล้วตามด้วยสิ่งที่เกิดเบื้องหลังในช่วงเวลาเดียวกัน กดที่ขั้นไหนก็ได้เพื่อดูข้อความจริงที่เข้าและออก และเหตุผลของขั้นนั้น

<WalkthroughLegend lang="th" />

run นี้บันทึกจริงเพื่อหน้านี้ ใน repo ตัวอย่างที่สร้างจาก fixture ของ eval slug จึงขึ้นต้นด้วย `eval-` ซึ่งทำให้ audit ไม่นับ run นี้เป็นงานของเจ้าของ ข้อความดึงจากไฟล์ของ run ด้วย `site/scripts/walkthrough.ts` ชื่อ agent ใช้ `nok` path ในเครื่องถูกย่อ และข้อความยาวบางช่วงถูกตัดให้สั้น ไม่มีการแต่งเพิ่ม
