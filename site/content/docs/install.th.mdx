คู่มือนี้สำหรับคนที่ไม่ได้เขียนโค้ด ทำตามทีละข้อ ใช้เวลาประมาณ 20-30 นาที ไม่รวมช่วงที่ agent ถามทำความรู้จักคุณ

twin คือผู้ช่วยของคุณเองที่ทำงานในแอป Claude Desktop รู้ว่าคุณมีอะไรค้าง จดสิ่งที่คุณสั่ง และค่อยๆ เรียนรู้ว่าคุณตัดสินใจอย่างไร คุณตั้งชื่อมันเองได้ ในคู่มือนี้ใช้ชื่อตัวอย่างว่า `nok`

สิ่งที่ต้องพิมพ์จะอยู่ในกรอบสีเทา ให้คัดลอกไปวางทั้งบรรทัดแล้วกด Enter ถ้าเครื่องของคุณเป็น Windows ให้กดแท็บ **Windows** ในแต่ละขั้น

## ก่อนเริ่ม

ต้องมี:

- คอมพิวเตอร์ Mac หรือ Windows ที่ต่ออินเทอร์เน็ต
- บัญชี Claude ที่ใช้ Claude Code ได้ (ถ้าเปิดแอปแล้วไม่เห็นแท็บ **Code** แปลว่าแพ็กเกจของคุณยังใช้ไม่ได้)

จะได้ใช้โปรแกรม "เทอร์มินัล" ไม่กี่ครั้ง เป็นหน้าต่างให้พิมพ์คำสั่ง

<Tabs groupId="os" persist items={['Mac', 'Windows']}>
  <Tab value="Mac">กด `Cmd + Space` พิมพ์ `Terminal` แล้วกด Enter</Tab>
  <Tab value="Windows">กดปุ่ม Windows พิมพ์ `PowerShell` แล้วกด Enter</Tab>
</Tabs>

## 1. ติดตั้ง Claude Desktop

<Steps>
  <Step>
    เปิด [claude.ai/download](https://claude.ai/download) แล้วดาวน์โหลดตัวที่ตรงกับเครื่อง
  </Step>
  <Step>
    <Tabs groupId="os" persist items={['Mac', 'Windows']}>
      <Tab value="Mac">เปิดไฟล์ `.dmg` แล้วลากไอคอน Claude ไปที่ Applications</Tab>
      <Tab value="Windows">เปิดไฟล์ที่ดาวน์โหลดแล้วกด Next จนจบ</Tab>
    </Tabs>
  </Step>
  <Step>
    เปิดแอป Claude แล้วเข้าสู่ระบบด้วยบัญชีของคุณ
  </Step>
  <Step>
    ดูด้านบนของแอปว่ามีแท็บ **Code** ถ้ามีก็พร้อมแล้ว
  </Step>
</Steps>

## 2. ติดตั้ง git

git ใช้ดาวน์โหลด twin มาไว้ในเครื่อง และใช้สำรองข้อมูลของคุณ

<Tabs groupId="os" persist items={['Mac', 'Windows']}>
  <Tab value="Mac">
    ในเทอร์มินัลพิมพ์

    ```bash
    git --version
    ```

    ถ้าขึ้นหน้าต่างให้ติดตั้ง "command line developer tools" ให้กด **Install** แล้วรอจนเสร็จ ถ้าขึ้นเลขเวอร์ชันเช่น `git version 2.x` แปลว่ามีอยู่แล้ว
  </Tab>
  <Tab value="Windows">
    เปิด [git-scm.com/download/win](https://git-scm.com/download/win) ดาวน์โหลดตัวติดตั้ง แล้วกด Next ทุกหน้าโดยไม่ต้องเปลี่ยนอะไร เสร็จแล้วปิดแล้วเปิด PowerShell ใหม่ แล้วพิมพ์

    ```powershell
    git --version
    ```

    เพื่อเช็กว่าติดตั้งแล้ว
  </Tab>
</Tabs>

## 3. ติดตั้ง Bun

Bun คือโปรแกรมที่ twin ใช้ทำงานเบื้องหลัง

<Tabs groupId="os" persist items={['Mac', 'Windows']}>
  <Tab value="Mac">
    ```bash
    curl -fsSL https://bun.sh/install | bash
    ```
  </Tab>
  <Tab value="Windows">
    ใน PowerShell พิมพ์

    ```powershell
    powershell -c "irm bun.sh/install.ps1 | iex"
    ```
  </Tab>
</Tabs>

เสร็จแล้ว**ปิดหน้าต่างเทอร์มินัลแล้วเปิดใหม่** จากนั้นพิมพ์

```bash
bun --version
```

ถ้าขึ้นเลขเวอร์ชัน (1.3 ขึ้นไป) แปลว่าใช้ได้

## 4. ดาวน์โหลด twin มาไว้ในเครื่อง

```bash
git clone https://github.com/GA-MO/twin.git my-twin
cd my-twin
bun install
```

จะได้โฟลเดอร์ชื่อ `my-twin` อยู่ในโฟลเดอร์ผู้ใช้ของคุณ จำที่อยู่นี้ไว้ ใช้ในขั้นต่อไป

<Tabs groupId="os" persist items={['Mac', 'Windows']}>
  <Tab value="Mac">`/Users/<ชื่อคุณ>/my-twin`</Tab>
  <Tab value="Windows">`C:\Users\<ชื่อคุณ>\my-twin`</Tab>
</Tabs>

## 5. ตั้งชื่อ agent

ยังอยู่ในโฟลเดอร์ `my-twin` พิมพ์

```bash
bun twin.ts setup
```

มันจะถามชื่อ ตั้งเป็นภาษาอังกฤษตัวเล็ก ไม่มีเว้นวรรค เช่น `nok` แล้วกด Enter

setup ทำให้เองทั้งหมด บันทึกชื่อ ตรวจว่าเครื่องมีอะไร ติดตั้งให้ agent โหลดตัวตนของคุณทุกครั้งที่เปิดคุย เปิดแถบสถานะงาน และตั้งให้มันอัปเดตข้อมูลทุก 10 นาทีกับสรุปตอน 08:30 ทุกเช้า

ถ้าในเครื่องนี้มี agent ตัวอื่นที่ตั้งค่าไว้แล้ว และอยากลอง twin โดยไม่ไปยุ่งกับตัวเดิม ให้ใช้คำสั่งนี้แทน

```bash
bun twin.ts setup --scope project --no-schedule
```

แบบนี้ตัวตนของ twin จะโหลดเฉพาะตอนเปิดคุยในโฟลเดอร์ `my-twin` และไม่ตั้งการอัปเดตอัตโนมัติ (สรุปงานจะอัปเดตตอนเปิดคุย) ถ้าลองแล้วชอบ รัน `bun twin.ts setup` อีกครั้งเพื่อติดตั้งเต็ม

<Callout type="info">
  ถ้าขึ้นข้อความ `⚠ ไม่พบคำสั่ง claude` ไม่ต้องตกใจ ปกติสำหรับคนที่ใช้แค่แอป Desktop ดูหัวข้อ[แก้ปัญหาที่เจอบ่อย](#แก้ปัญหาที่เจอบ่อย)ด้านล่าง
</Callout>

## 6. เปิด twin ในแท็บ Code

<Steps>
  <Step>
    เปิดแอป Claude แล้วกดแท็บ **Code**
  </Step>
  <Step>
    กด **New** เพื่อเริ่มคุยใหม่
  </Step>
  <Step>
    ใต้ช่องพิมพ์จะมีชื่อโฟลเดอร์อยู่ ให้กดที่ชื่อนั้น แล้วเลือก **Open folder...** จากนั้นเลือกโฟลเดอร์ `my-twin` (ต้องเลือกโฟลเดอร์จากตรงนี้ ในหน้าคุยใหม่ ไม่ใช่เลือกโฟลเดอร์ไว้ก่อนแล้วค่อยกด New)
  </Step>
  <Step>
    ครั้งแรกจะขึ้นหน้าต่าง **Trust this workspace?** ให้กดปุ่ม **Trust workspace** ถ้าไม่กด agent จะโหลดตัวตนและสรุปงานไม่ได้
  </Step>
  <Step>
    ถ้าแอปถามเรื่องเปิดปลั๊กอินชื่อ `twin` หรือ marketplace ชื่อ `twin-mods` ให้กดอนุญาต นี่คือแถบสถานะงาน (เครื่องที่เคยติดตั้งปลั๊กอินนี้แล้วจะไม่เห็นหน้าต่างนี้)
  </Step>
</Steps>

พิมพ์ว่า `มีอะไรค้าง` ถ้า agent ตอบโดยขึ้นต้นด้วยชื่อของมัน (เช่น "nok") และบอกว่ายังไม่ได้ onboard แปลว่าทุกอย่างพร้อม

<Callout type="warn">
  ใช้แท็บ **Code** เท่านั้น แท็บ Chat ไม่ได้ต่อกับ twin
</Callout>

## 7. เช็กว่าแถบสถานะงานทำงาน

แถบสถานะงาน (mod) คือกรอบสีรุ้งที่อยู่เหนือช่องพิมพ์ มันโชว์งานที่ agent ส่งไปทำ และปุ่มให้คุณอนุมัติหรือตอบคำถามได้ในคลิกเดียว

- ตอนยังไม่มีงานที่ส่งไป **แถบจะยังไม่ขึ้น** เป็นเรื่องปกติ
- เช็กได้โดยพิมพ์ `/twin` ในช่องพิมพ์ แล้วกด **Enter สองครั้ง** ครั้งแรกเลือก `/twin` จากเมนูที่เด้งขึ้นมา ครั้งที่สองส่งคำสั่ง ถ้ามีแผงด้านข้างเปิดขึ้นมาพร้อมชื่อ agent ของคุณ (ตอนยังไม่มีงานจะเขียนว่า Nothing open) แปลว่าแถบทำงานแล้ว
- เมื่อมีงานที่รอคุณ แถบจะขึ้นเหนือช่องพิมพ์ ปุ่มที่เจอบ่อยมีดังนี้
  - **Approve** อนุมัติตามที่งานขอ
  - **Answer** ใส่ข้อความตั้งต้นไว้ในช่องพิมพ์ให้คุณพิมพ์คำตอบต่อเอง
  - **Report** กางรายงานของงานนั้นอ่านในการ์ด
  - **… here** รับงานที่ส่งมาจากหน้าต่างคุยอื่นมาทำต่อในหน้าต่างนี้
- กดปุ่มไปแล้ว ปุ่มจะกลายเป็นข้อความ "Sent: … Waiting for" ตามด้วยชื่อ agent เพื่อไม่ให้กดซ้ำ
- ตอนที่ agent ถามคำถามแบบมีตัวเลือกค้างอยู่ แถบเหนือช่องพิมพ์จะหลบไปชั่วคราว ระหว่างนั้นเปิด `/twin` แล้วกดปุ่มในแผงด้านข้างได้ตามปกติ

## 8. ให้ agent รู้จักคุณ (ครั้งแรก)

พิมพ์

```text
onboard
```

- agent จะขออนุญาตก่อนว่าอ่านประวัติที่คุณเคยคุยกับ Claude ได้ไหม ให้หรือไม่ให้ก็ได้
- ถ้าใช้ Claude บนเว็บหรือมือถือเป็นหลัก มันจะบอกวิธี export ประวัติ แล้วให้คุณวางไฟล์ `conversations.json` ไว้ในโฟลเดอร์ `my-twin/profile/imports/`
- จากนั้นมันจะถามทีละข้อเป็นสถานการณ์จริง มีตัวเลือกให้ ตอบเป็นเลขหรือพิมพ์เองก็ได้ ข้อไหนไม่อยากตอบพิมพ์ `ข้าม`
- ถามชุดละ 5 ข้อ หยุดเมื่อไหร่ก็ได้ วันหลังเปิดมาตอบต่อจากข้อเดิมได้เลย
- เสร็จแล้วมันจะสรุปว่าเข้าใจคุณว่าอย่างไร สิ่งที่ห้ามทำแทนคุณ และเรื่องไหนต้องถามก่อน ตรงไหนไม่ใช่ บอกแก้ได้ทันที

หลังจากนั้นทุกวันมันจะขอถามเพิ่ม 1-3 ข้อในเรื่องที่ยังรู้จักคุณน้อย พิมพ์ `ถามฉันหน่อย` เมื่อสะดวก

## 9. ใช้ทุกวัน

เปิดแท็บ Code ในโฟลเดอร์ `my-twin` แล้วคุยเป็นภาษาปกติ ตัวอย่าง:

| พิมพ์ | ได้ |
|---|---|
| มีอะไรค้าง | สรุปสิ่งที่รอคุณ เรียงตามความสำคัญ |
| จำไว้ว่า … | จดเป็นความจำ |
| เตือนฉันว่า … ภายในวันศุกร์ | จดเป็นงานที่ต้องทำ พร้อมกำหนดวัน |
| สรุปประชุม แล้ววางโน้ตประชุม | การตัดสินใจ งานของคุณ และงานที่ต้องส่งต่อ |
| จด feedback: ไม่ควร … | จดไว้ปรับตัว |
| improve | เอา feedback ที่จดไว้มาปรับวิธีทำงานของ agent |

อ่านเพิ่มใน[ใช้ทุกวัน](/th/docs/daily-use)

## สำรองข้อมูลและย้ายเครื่อง

ข้อมูลของคุณ (ตัวตน โน้ต บันทึกประจำวัน) อยู่ในโฟลเดอร์ `my-twin` บนเครื่องคุณเท่านั้น ไม่ถูกส่งไปที่ repo ต้นทาง ถ้าอยากสำรองไว้นอกเครื่อง ให้สร้าง repo ส่วนตัว (private) ไว้หนึ่งที่ ถ้าไม่เคยสร้าง ขอให้คนที่แนะนำ twin ช่วย แล้วพิมพ์ในโฟลเดอร์ `my-twin`

```bash
git remote add backup <ที่อยู่ repo ส่วนตัว>
```

จากนั้นระบบจะสำรองให้เองทุกชั่วโมง วิธีย้ายเครื่องอยู่ใน[ข้อมูลของคุณ](/th/docs/concepts/your-data#ย้ายไปเครื่องใหม่)

## ถอนการติดตั้ง

ในเทอร์มินัล ไปที่โฟลเดอร์ `my-twin` แล้วพิมพ์

```bash
bun twin.ts uninstall
```

คำสั่งนี้เอาทุกอย่างที่ setup ติดตั้งออก ได้แก่ การโหลดตัวตนตอนเริ่มคุย ลิงก์ skill แถบสถานะงาน และการอัปเดตอัตโนมัติ ข้อมูลของคุณในโฟลเดอร์ `my-twin` ยังอยู่ ถ้าไม่ใช้แล้วจริงๆ ลบโฟลเดอร์ `my-twin` ทิ้งได้เลย ส่วน Bun, git และแอป Claude ถอนแบบโปรแกรมทั่วไปของเครื่องคุณ
