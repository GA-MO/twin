ต้องมีเครื่อง Mac หรือ Windows และบัญชี Claude ที่เห็นแท็บ **Code** ในแอป Claude

<Steps>
<Step>

### ลงแอป Claude

ดาวน์โหลดจาก [claude.ai/download](https://claude.ai/download) ติดตั้ง แล้วเข้าสู่ระบบ ดูว่ามีแท็บ **Code** อยู่ด้านบน

</Step>
<Step>

### วางคำสั่งบรรทัดเดียวในเทอร์มินัล

เปิดเทอร์มินัล Mac กด `Cmd + Space` แล้วพิมพ์ `Terminal` ส่วน Windows กดปุ่ม Windows แล้วพิมพ์ `PowerShell` วางบรรทัดนี้แล้วกด Enter

<Tabs groupId="os" persist items={["Mac", "Windows"]}>
<Tab value="Mac">

```bash
curl -fsSL https://ga-mo.github.io/twin/install.sh | sh
```

</Tab>
<Tab value="Windows">

```powershell
irm https://ga-mo.github.io/twin/install.ps1 | iex
```

</Tab>
</Tabs>

<Replay of="install" lang="th" />

มันติดตั้งสิ่งที่ยังขาดให้เอง เอา twin ไว้ในโฟลเดอร์ `my-twin` ในโฟลเดอร์ผู้ใช้ แล้วถามชื่อ agent ให้ตั้งเป็นภาษาอังกฤษตัวเล็ก เช่น `nok` ข้อความเป็นภาษาไทยเมื่อเครื่องตั้งภาษาหรือภูมิภาคเป็นไทย นอกนั้นเป็นภาษาอังกฤษ

ถ้า Mac ขึ้นหน้าต่างให้ติดตั้ง "command line developer tools" ให้กด **Install** รอจนเสร็จ แล้ววางบรรทัดเดิมอีกครั้ง

</Step>
<Step>

### เปิดแล้วทักทาย

1. ในแอป Claude กด **Code** แล้วกด **New**
2. กดชื่อโฟลเดอร์ใต้ช่องพิมพ์ เลือก **Open folder...** แล้วเลือก `my-twin`
3. กด **Trust workspace** ถ้าแอปถามเรื่องปลั๊กอิน `twin` ให้กดอนุญาต
4. พิมพ์ `onboard`

agent จะขอก่อนว่าอ่านประวัติที่คุณเคยคุยกับ Claude ได้ไหม แล้วถามทีละไม่กี่ข้อ มีตัวเลือกให้กด หยุดเมื่อไหร่ก็ได้ วันหลังมาตอบต่อได้

</Step>
</Steps>

เท่านี้เลย ต่อไปเปิดแท็บ **Code** ในโฟลเดอร์ `my-twin` แล้วคุยภาษาปกติ แท็บ **Chat** ไม่ได้ต่อกับ twin

## ใช้เทอร์มินัลเป็นอยู่แล้ว

ใช้บรรทัดเดียวกันได้เลย แล้วรัน `cd ~/my-twin && claude` ตัวเลือกอย่างโฟลเดอร์โค้ด (`--dev`) หรือลอง twin คู่กับ agent ตัวเดิม (`--scope project`) อยู่ใน[แก้ปัญหา](/th/docs/troubleshooting#ตัวเลือกตอนติดตั้ง)
