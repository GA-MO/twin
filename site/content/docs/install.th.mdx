คู่มือนี้สำหรับคนที่ไม่ได้เขียนโค้ด ทำตามทีละข้อ ใช้เวลาประมาณ 10-15 นาที ไม่รวมช่วงที่ agent ถามทำความรู้จักคุณ

twin คือผู้ช่วยของคุณเองที่ทำงานในแอป Claude Desktop รู้ว่าคุณมีอะไรค้าง จดสิ่งที่คุณสั่ง และค่อยๆ เรียนรู้ว่าคุณตัดสินใจอย่างไร คุณตั้งชื่อมันเองได้ ในคู่มือนี้ใช้ชื่อตัวอย่างว่า `nok`

สิ่งที่ต้องพิมพ์จะอยู่ในกรอบสีเทา ให้คัดลอกไปวางทั้งบรรทัดแล้วกด Enter ถ้าเครื่องของคุณเป็น Windows ให้กดแท็บ **Windows** ในแต่ละขั้น

## ก่อนเริ่ม

ต้องมี:

- คอมพิวเตอร์ Mac หรือ Windows ที่ต่ออินเทอร์เน็ต
- บัญชี Claude ที่ใช้ Claude Code ได้ (ถ้าเปิดแอปแล้วไม่เห็นแท็บ **Code** แปลว่าแพ็กเกจของคุณยังใช้ไม่ได้)

จะได้ใช้โปรแกรม "เทอร์มินัล" ไม่กี่ครั้ง เป็นหน้าต่างให้พิมพ์คำสั่ง

<Tabs groupId="os" persist items={['Mac', 'Windows']}>
  <Tab value="Mac">กด `Cmd + Space` พิมพ์ `Terminal` แล้วกด Enter</Tab>
  <Tab value="Windows">กดปุ่ม Windows พิมพ์ `PowerShell` แล้วกด Enter</Tab>
</Tabs>

<Steps>

  </Step>
  <Step>

    </Tabs>

## 2. ติดตั้ง twin

คัดลอกบรรทัดนี้ไปวางในเทอร์มินัลแล้วกด Enter

<Tabs items={["Mac", "Windows"]}>
  <Tab value="Mac">
    ```bash
    curl -fsSL https://ga-mo.github.io/twin/install.sh | sh
    ```
  </Tab>
  <Tab value="Windows">
    ```powershell
    irm https://ga-mo.github.io/twin/install.ps1 | iex
    ```
  </Tab>
</Tabs>

installer ทำ 4 อย่าง และบอกทีละขั้นว่าทำอะไรอยู่

1. เช็ก git ถ้าเป็น Mac ที่ยังไม่มี git จะขึ้นหน้าต่างให้ติดตั้ง "command line developer tools" ให้กด **Install** รอจนเสร็จ แล้ววางบรรทัดเดิมอีกครั้ง ส่วน Windows ติดตั้ง git ให้เอง
2. ติดตั้ง Bun โปรแกรมที่ twin ใช้ทำงานเบื้องหลัง
3. ติดตั้งคำสั่ง `claude` ถ้าขั้นนี้ไม่สำเร็จ twin ยังใช้ในแอป Desktop ได้ตามปกติ ดูหัวข้อ "ไม่พบคำสั่ง claude" ด้านล่าง
4. ดาวน์โหลด twin ไว้ในโฟลเดอร์ `my-twin` ในโฟลเดอร์ผู้ใช้ของคุณ แล้วถามชื่อ agent ตั้งเป็นภาษาอังกฤษตัวเล็ก ไม่มีเว้นวรรค เช่น `nok` แล้วกด Enter

โฟลเดอร์อยู่ที่ Mac: `/Users/<ชื่อคุณ>/my-twin` · Windows: `C:\Users\<ชื่อคุณ>\my-twin` จำที่อยู่นี้ไว้ ใช้ในขั้นต่อไป

จากนั้น setup ทำให้เองทั้งหมด บันทึกชื่อ ตรวจว่าเครื่องมีอะไร ติดตั้งให้ agent โหลดตัวตนของคุณทุกครั้งที่เปิดคุย เปิดแถบสถานะงาน และตั้งให้มันอัปเดตข้อมูลทุก 10 นาทีกับสรุปตอน 08:30 ทุกเช้า

วางบรรทัดเดิมซ้ำเมื่อไหร่ก็ได้ ไม่มีอะไรพัง ถ้าติดตั้งไว้แล้ว มันจะอัปเดต twin ให้แทนการติดตั้งใหม่

ถ้าในเครื่องนี้มี agent ตัวอื่นที่ตั้งค่าไว้แล้ว และอยากลอง twin โดยไม่ไปยุ่งกับตัวเดิม ให้ใช้บรรทัดนี้แทน

<Tabs items={["Mac", "Windows"]}>
  <Tab value="Mac">
    ```bash
    curl -fsSL https://ga-mo.github.io/twin/install.sh | sh -s -- --scope project --no-schedule
    ```
  </Tab>
  <Tab value="Windows">
    ```powershell
    & ([scriptblock]::Create((irm https://ga-mo.github.io/twin/install.ps1))) --scope project --no-schedule
    ```
  </Tab>
</Tabs>

แบบนี้ตัวตนของ twin จะโหลดเฉพาะตอนเปิดคุยในโฟลเดอร์ `my-twin` และไม่ตั้งการอัปเดตอัตโนมัติ (สรุปงานจะอัปเดตตอนเปิดคุย) ถ้าลองแล้วชอบ ไปที่โฟลเดอร์ `my-twin` แล้วรัน `bun twin.ts setup` เพื่อติดตั้งเต็ม

<Callout type="info">
  ถ้าขึ้นข้อความ `⚠ ไม่พบคำสั่ง claude` ไม่ต้องตกใจ ปกติสำหรับคนที่ใช้แค่แอป Desktop ดูหัวข้อ[แก้ปัญหาที่เจอบ่อย](#แก้ปัญหาที่เจอบ่อย)ด้านล่าง
</Callout>

## 3. เปิด twin ในแท็บ Code

<Steps>
  <Step>
    เปิดแอป Claude แล้วกดแท็บ **Code**
  </Step>
  <Step>
    กด **New** เพื่อเริ่มคุยใหม่
  </Step>
  <Step>
    ใต้ช่องพิมพ์จะมีชื่อโฟลเดอร์อยู่ ให้กดที่ชื่อนั้น แล้วเลือก **Open folder...** จากนั้นเลือกโฟลเดอร์ `my-twin` (ต้องเลือกโฟลเดอร์จากตรงนี้ ในหน้าคุยใหม่ ไม่ใช่เลือกโฟลเดอร์ไว้ก่อนแล้วค่อยกด New)
  </Step>
  <Step>
    ครั้งแรกจะขึ้นหน้าต่าง **Trust this workspace?** ให้กดปุ่ม **Trust workspace** ถ้าไม่กด agent จะโหลดตัวตนและสรุปงานไม่ได้
  </Step>
  <Step>
    ถ้าแอปถามเรื่องเปิดปลั๊กอินชื่อ `twin` หรือ marketplace ที่ชื่อขึ้นต้นด้วย `twin-mods-` ให้กดอนุญาต นี่คือแถบสถานะงาน (ถามครั้งเดียวต่อโฟลเดอร์ twin และถามอีกครั้งหลังอัปเดตจากรุ่นที่ใช้ชื่อ `twin-mods`)
  </Step>
</Steps>

พิมพ์ว่า `มีอะไรค้าง` ถ้า agent ตอบโดยขึ้นต้นด้วยชื่อของมัน (เช่น "nok") และบอกว่ายังไม่ได้ onboard แปลว่าทุกอย่างพร้อม

<Callout type="warn">
  ใช้แท็บ **Code** เท่านั้น แท็บ Chat ไม่ได้ต่อกับ twin
</Callout>

## 4. เช็กว่าแถบสถานะงานทำงาน

แถบสถานะงาน (mod) อยู่เหนือช่องพิมพ์ งานที่รอคุณขึ้นเป็นการ์ดในกรอบสีรุ้ง พร้อมปุ่มให้อนุมัติหรือตอบคำถามได้ในคลิกเดียว ใต้กรอบมีบรรทัดสถานะนับงานที่เหลือ เช่น `● nok · 1 waiting on you · 1 in progress`

- ตอนยังไม่มีงานที่ส่งไป **แถบจะยังไม่ขึ้น** เป็นเรื่องปกติ
- เช็กได้โดยพิมพ์ `/twin` ในช่องพิมพ์ แล้วกด **Enter สองครั้ง** ครั้งแรกเลือก `/twin` จากเมนูที่เด้งขึ้นมา ครั้งที่สองส่งคำสั่ง ถ้ามีแผงด้านข้างเปิดขึ้นมาพร้อมชื่อ agent ของคุณ (ตอนยังไม่มีงานจะเขียนว่า Nothing open) แปลว่าแถบทำงานแล้ว
- เมื่อมีงานที่รอคุณ แถบจะขึ้นเหนือช่องพิมพ์ ปุ่มที่เจอบ่อยมีดังนี้
  - **Approve** อนุมัติตามที่งานขอ
  - **Answer** ใส่ข้อความตั้งต้นไว้ในช่องพิมพ์ให้คุณพิมพ์คำตอบต่อเอง
  - **Report** กางรายงานของงานนั้นอ่านในการ์ด
  - **Ship UAT** ส่งงานที่เสร็จแล้วแต่ยังมี commit ที่ไม่ได้ push ขึ้น UAT
  - **… here** รับงานที่ส่งมาจากหน้าต่างคุยอื่นมาทำต่อในหน้าต่างนี้
- กดปุ่มไปแล้ว ปุ่มจะกลายเป็นข้อความ "Sent: … Waiting for" ตามด้วยชื่อ agent เพื่อไม่ให้กดซ้ำ
- ตอนที่ agent ถามคำถามแบบมีตัวเลือกค้างอยู่ แถบเหนือช่องพิมพ์จะหลบไปชั่วคราว ระหว่างนั้นเปิด `/twin` แล้วกดปุ่มในแผงด้านข้างได้ตามปกติ

## 5. ให้ agent รู้จักคุณ (ครั้งแรก)

พิมพ์

```text
onboard
```

- agent จะขออนุญาตก่อนว่าอ่านประวัติที่คุณเคยคุยกับ Claude ได้ไหม ให้หรือไม่ให้ก็ได้
- ถ้าใช้ Claude บนเว็บหรือมือถือเป็นหลัก มันจะบอกวิธี export ประวัติ แล้วให้คุณวางไฟล์ `conversations.json` ไว้ในโฟลเดอร์ `my-twin/profile/imports/`
- จากนั้นมันจะถามทีละข้อเป็นสถานการณ์จริง มีตัวเลือกให้ ตอบเป็นเลขหรือพิมพ์เองก็ได้ ข้อไหนไม่อยากตอบพิมพ์ `ข้าม`
- ถามชุดละ 5 ข้อ หยุดเมื่อไหร่ก็ได้ วันหลังเปิดมาตอบต่อจากข้อเดิมได้เลย
- เสร็จแล้วมันจะสรุปว่าเข้าใจคุณว่าอย่างไร สิ่งที่ห้ามทำแทนคุณ และเรื่องไหนต้องถามก่อน ตรงไหนไม่ใช่ บอกแก้ได้ทันที

หลังจากนั้นทุกวันมันจะขอถามเพิ่ม 1-3 ข้อในเรื่องที่ยังรู้จักคุณน้อย พิมพ์ `ถามฉันหน่อย` เมื่อสะดวก

## 6. ใช้ทุกวัน

เปิดแท็บ Code ในโฟลเดอร์ `my-twin` แล้วคุยเป็นภาษาปกติ ตัวอย่าง:

| พิมพ์ | ได้ |
|---|---|
| มีอะไรค้าง | สรุปสิ่งที่รอคุณ เรียงตามความสำคัญ |
| จำไว้ว่า … | จดเป็นความจำ |
| เตือนฉันว่า … ภายในวันศุกร์ | จดเป็นงานที่ต้องทำ พร้อมกำหนดวัน |
| สรุปประชุม แล้ววางโน้ตประชุม | การตัดสินใจ งานของคุณ และงานที่ต้องส่งต่อ |
| จด feedback: ไม่ควร … | จดไว้ปรับตัว |
| improve | เอา feedback ที่จดไว้มาปรับวิธีทำงานของ agent |

อ่านเพิ่มใน[ใช้ทุกวัน](/th/docs/daily-use)

## สำรองข้อมูลและย้ายเครื่อง

ข้อมูลของคุณ (ตัวตน โน้ต บันทึกประจำวัน) อยู่ในโฟลเดอร์ `my-twin` บนเครื่องคุณเท่านั้น ไม่ถูกส่งไปที่ repo ต้นทาง ถ้าอยากสำรองไว้นอกเครื่อง ให้สร้าง repo ส่วนตัว (private) ไว้หนึ่งที่ ถ้าไม่เคยสร้าง ขอให้คนที่แนะนำ twin ช่วย แล้วพิมพ์ในโฟลเดอร์ `my-twin`

```bash
git remote add backup <ที่อยู่ repo ส่วนตัว>
```

จากนั้นระบบจะสำรองให้เองทุกชั่วโมง วิธีย้ายเครื่องอยู่ใน[ข้อมูลของคุณ](/th/docs/concepts/your-data#ย้ายไปเครื่องใหม่)

## อัปเดตเป็นรุ่นใหม่

เมื่อมี twin รุ่นใหม่ สรุปงานตอนเช้าจะบอก เช่น "มี nok รุ่นใหม่ 3 เรื่อง" ให้พิมพ์ `update` ในหน้าคุย หรือในเทอร์มินัล ไปที่โฟลเดอร์ `my-twin` แล้วพิมพ์

```bash
bun twin.ts update
```

วางบรรทัดติดตั้งในขั้นที่ 2 ซ้ำก็ได้ผลเหมือนกัน

คำสั่งนี้ดึง twin รุ่นใหม่มา ลง dependency ที่เปลี่ยน แล้วตั้งค่าซ้ำให้เอง พร้อมบอกว่ามีอะไรใหม่ ข้อมูลของคุณใน `profile/`, `notes/` และ `journal/` ไม่ถูกแตะ ถ้าคุณแก้ไฟล์ของ engine เองไว้ คำสั่งจะหยุดและบอกชื่อไฟล์ก่อน ถ้ารุ่นใหม่ติดตั้งไม่ผ่าน มันจะถอยกลับไปรุ่นเดิมให้ ไม่มีอะไรเปลี่ยน

ถ้าเครื่องบอกว่าไม่รู้จักคำสั่ง update แปลว่า twin ของคุณเก่ากว่าคำสั่งนี้ ให้พิมพ์ `git pull` แล้ว `bun twin.ts setup` หนึ่งครั้ง ครั้งต่อไปใช้ update ได้

## ถอนการติดตั้ง

ในเทอร์มินัล ไปที่โฟลเดอร์ `my-twin` แล้วพิมพ์

```bash
bun twin.ts uninstall
```

คำสั่งนี้เอาทุกอย่างที่ setup ติดตั้งออก ได้แก่ การโหลดตัวตนตอนเริ่มคุย ลิงก์ skill แถบสถานะงาน และการอัปเดตอัตโนมัติ ข้อมูลของคุณในโฟลเดอร์ `my-twin` ยังอยู่

ก่อนเอาอะไรออก มันสำรองข้อมูลให้อีกครั้ง บรรทัดท้ายๆ จะบอกว่าลบโฟลเดอร์ได้หรือยัง

- ถ้าตั้ง repo สำรองไว้ มันจะ push สำเนาล่าสุดไปแล้วบอกว่าลบโฟลเดอร์ `my-twin` ได้ ติดตั้งใหม่วันหลังก็ดึงข้อมูลคืนจาก backup ได้
- ถ้า push ไม่สำเร็จ มันจะบอกว่าอย่าเพิ่งลบ ให้แก้ตามที่บอกแล้วรัน uninstall ซ้ำ
- ถ้ายังไม่มี repo สำรอง มันจะเตือนว่าลบโฟลเดอร์แล้วข้อมูลหายถาวร

ส่วน Bun, git และแอป Claude ถอนแบบโปรแกรมทั่วไปของเครื่องคุณ
