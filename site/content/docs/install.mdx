---
title: Install
description: Three steps and about five minutes. Get the Claude app, paste one line, and say hello to your agent.
---

You need a Mac or Windows computer and a Claude plan that shows a **Code** tab in the Claude app.

<Steps>
<Step>

### Get the Claude app

Download it from [claude.ai/download](https://claude.ai/download), install it, and log in. Check that there is a **Code** tab at the top.

</Step>
<Step>

### Paste one line in the terminal

Open the terminal. On a Mac, press `Cmd + Space` and type `Terminal`. On Windows, press the Windows key and type `PowerShell`. Paste this line and press Enter:

<Tabs groupId="os" persist items={["Mac", "Windows"]}>
<Tab value="Mac">

```bash
curl -fsSL https://ga-mo.github.io/twin/install.sh | sh
```

</Tab>
<Tab value="Windows">

```powershell
irm https://ga-mo.github.io/twin/install.ps1 | iex
```

</Tab>
</Tabs>

<Replay of="install" lang="en" />

It installs what is missing, puts twin in a folder named `my-twin` in your home folder, and asks for your agent's name. Use lowercase letters, for example `nok`. It speaks Thai when your computer is set to the Thai language or region, and English otherwise.

If a Mac asks to install "command line developer tools", click **Install**, wait, and paste the line again.

</Step>
<Step>

### Open it and say hello

1. In the Claude app, click **Code**, then **New**.
2. Click the folder name under the message box, select **Open folder...**, and pick `my-twin`.
3. Click **Trust workspace**. If the app asks about a `twin` plugin, allow it.
4. Type `onboard`.

The agent asks whether it may read your past Claude conversations, then asks you a few questions at a time, with options to pick. Stop whenever you like. It continues another day.

</Step>
</Steps>

That's it. From now on, open the **Code** tab in `my-twin` and talk in plain words. The **Chat** tab is not connected to twin.

## Already live in a terminal?

The same line works. Then run `cd ~/my-twin && claude`. Setup options such as your code folder (`--dev`) or trying twin beside another agent (`--scope project`) are in [Troubleshooting](/docs/troubleshooting#setup-options).
