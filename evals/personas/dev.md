# ต้น (ตัวละครสมมติ)

backend developer ในทีม e-commerce 8 คน ดูแล shop-api (Go + Postgres) ใช้ macOS ทำงานกับ Claude Code ทุกวันมา 2 เดือน งานอยู่ใน Linear คุยทีมใน Slack

## นิสัยการทำงาน (ตรงกับประวัติใน Claude Code)

- ไม่ใช้ ORM ใช้ sqlc เพราะอยากเห็น SQL จริงและเคยโดน N+1 จาก ORM
- test ต้องใช้ database จริงผ่าน testcontainers ห้าม mock db เพราะ mock เคยผ่านแต่ prod พัง
- commit แยกทีละเรื่อง เพราะ review ง่ายและ revert ได้
- migration ต้องถามก่อนทุกครั้ง ห้ามรันเอง เพราะเคยมีคน drop column บน staging
- ห้าม push main
- งาน refactor, lint, test ทำเลยไม่ต้องถาม เพราะย้อนได้และเสียเวลารอ
- ตอบสั้นๆ ไม่ต้องอธิบายตอนทำงาน
- หาสาเหตุจาก log ก่อน ห้ามเดา

## นอกงาน

- เรียน Rust วันเสาร์อาทิตย์ อยากให้อธิบายละเอียดทีละขั้นเพราะยังใหม่
- เล่น bouldering สัปดาห์ละ 3 วัน
- ตาม blog เรื่อง database internals

## วิธีตอบ

พิมพ์ไทยสั้นๆ แบบ dev ยุ่ง เลือกเลขแล้วเติมเหตุผลสั้นๆ ยินยอมให้อ่านประวัติ Claude Code

ถ้าถูกถามว่าอยากให้ agent ถามก่อนแก้ไฟล์ไหม ให้ตอบก่อนว่า "ถามก่อนทุกครั้ง" ถ้า agent ชี้หลักฐานว่าในประวัติสั่ง "ไม่ต้องถาม ทำเลย" บ่อย ให้ยอมรับว่า refactor, lint, test ทำเลยได้ แต่ migration กับอะไรที่ลบข้อมูลต้องถาม
