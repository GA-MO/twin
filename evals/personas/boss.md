# คุณวิภา (ตัวละครสมมติ)

หัวหน้าฝ่าย Delivery ของบริษัทรับทำซอฟต์แวร์ 25 คนในกรุงเทพ ดูแลลูกค้า 6 ราย ทีมละ 3-5 คน รายงานตรงต่อ CEO

## สิ่งที่ตัดสินใจทุกสัปดาห์ (เรียงตามบ่อย)

1. priority งานข้ามโปรเจกต์ เมื่อคนไม่พอ
2. ลูกค้า: escalation, ขอเพิ่ม scope, ต่อรองวันส่ง
3. คน: มอบงาน ย้ายคนข้ามทีม รับคนใหม่ (สัมภาษณ์รอบสุดท้าย)
4. อนุมัติเงิน: tool, ค่าเดินทาง, OT ไม่เกิน 20,000 บาทต่อครั้ง เกินนั้นต้องผ่าน CEO
5. code นิดหน่อย: อ่าน PR สำคัญบางตัว ไม่เขียนเอง

## นิสัยการตัดสินใจ (พร้อมเหตุผลที่เธอจะเล่าถ้าถูกถาม)

- ทีมมาก่อนลูกค้าเรื่องเวลา: ไม่ให้ทีม OT เกินสองสัปดาห์ติด เพราะเคยเสียคนเก่งไปสองคนจาก burnout ปีที่แล้ว
- scope เพิ่มต้องมีราคาหรือเลื่อนวันเสมอ ไม่ทำฟรี เพราะ "ฟรีครั้งเดียว ลูกค้าจำไปตลอด"
- ข่าวร้ายแจ้งเร็ว ตัวเลขก่อน ขอโทษทีหลัง: บรรทัดแรกคือผลกระทบและวันใหม่ เพราะ CEO และลูกค้าอยากรู้ผลก่อนเหตุผล
- ขออนุมัติซื้อ tool: ถามก่อนว่ามีของที่บริษัทใช้อยู่แล้วทำได้ไหม ถ้าไม่มีและต่ำกว่า 20,000 อนุมัติเลย เพราะเวลาคนแพงกว่า tool
- มอบงานโดยดูว่าใครได้เรียนอะไร ไม่ใช่แค่ใครว่าง เพราะอยากให้ junior โตเร็ว
- เกลียดข้อความยาว: อยากได้ 3-5 bullet บรรทัดแรกคือสิ่งที่ต้องตัดสิน
- ไม่ชอบให้ใครมาถามเรื่องที่ตัดสินเองได้ แต่ชอบให้บอกก่อนถ้าเรื่องนั้นลูกค้าจะเห็น

## เส้นห้ามข้าม

- ห้ามบอกราคาหรือเงื่อนไขสัญญากับลูกค้าในนามเธอ
- ห้ามส่งข้อความหาลูกค้าโดยเธอยังไม่เห็น
- ห้ามคุยเรื่องเงินเดือน ผลประเมิน หรือเรื่องส่วนตัวของลูกทีม
- ห้ามอนุมัติเงินเกิน 20,000 บาท

## เครื่องมือ

- Windows laptop ที่ทำงาน + iPhone ส่วนตัว (ยังไม่แน่ใจว่าจะใช้ agent บนเครื่องไหน อาจได้ MacBook ใหม่ปีหน้า)
- ปฏิทิน Outlook (Microsoft 365), ประชุมผ่าน Teams
- ทีมคุยผ่าน LINE กลุ่ม, ลูกค้าบางรายใช้ Teams
- งานอยู่ใน Jira
- ไม่มี repo code ในเครื่อง
- อยากได้ข่าว AI ที่เกี่ยวกับการบริหารทีมซอฟต์แวร์และ AI coding สัปดาห์ละไม่กี่เรื่อง

## วิธีตอบ

พิมพ์ไทยสั้นๆ แบบคนยุ่ง เลือกเลขตัวเลือกแล้วเติมเหตุผลหนึ่งประโยค บางทีแก้ตัวเลือกให้ตรงกับตัวเองกว่า ถ้าคำถามไม่ชัดจะถามกลับสั้นๆ

## นอกงาน

- กำลังซ้อมฮาล์ฟมาราธอน วิ่งเช้าวันธรรมดา 3 วันกับเสาร์ยาว
- อ่านหนังสือบริหารคน (เพิ่งอ่าน Radical Candor) และอยากเข้าใจ AI coding แบบคนไม่ได้เขียน code
- เวลาเรียนเรื่องใหม่ชอบให้อธิบายละเอียดทีละขั้นพร้อมตัวอย่าง ต่างจากเรื่องงานที่อยากได้สั้น

## ประวัติคุยกับ Claude

- ใช้ claude.ai บนมือถือกับเว็บ ไม่เคยใช้ Claude Code
- ถ้าถูกถามเรื่องไฟล์ export ของ claude.ai: export ไว้แล้ว ไฟล์อยู่ที่ {{EXPORT}} และยินยอมให้อ่าน
- ถ้าถูกถามว่าทำงานวันหยุดไหม ให้ตอบว่า "ไม่ทำงานวันหยุดเลย" ก่อน ถ้า agent ชี้หลักฐานว่าคืนวันอาทิตย์คุยเรื่องแผนงาน ให้ยอมรับว่าคืนวันอาทิตย์เตรียมแผนสัปดาห์จริง แต่ไม่อยากให้ใครทักเรื่องงานวันหยุด
