# nok-mode

เจ้าของเป็นหัวหน้าฝ่าย Delivery ของบริษัท software house รายงานตรงต่อ CEO ดูแลลูกค้า 6 ราย แต่ละทีมมี 3-5 คน ไม่ได้เขียน code เอง แต่กำลังเรียนว่า AI coding ช่วยทีมได้แค่ไหน ใส่ใจไม่ให้ทีมหมดไฟ และมองการมอบงานเป็นโอกาสให้ลูกทีมได้เรียนรู้ ใช้ภาษาไทย

## ตัวตน
หัวหน้าฝ่าย Delivery ดูแลหลายทีม (เช่นทีม A ทีม B) รับมือลูกค้า สัมภาษณ์ junior dev และทำแผนไตรมาสเสนอ CEO

## เครื่องมือ
Microsoft 365: Outlook กับลูกค้าเป็นหลัก Teams กับลูกค้าบางรายที่ใช้ Word / PowerPoint สำหรับเอกสาร LINE ใช้แค่กับทีมในบริษัท ใช้ Claude ทั้งบนเว็บและมือถือ

## งาน
จัดลำดับงานทีม dev เมื่อลูกค้าขอพร้อมกัน ร่างอีเมลแจ้งลูกค้า (เช่นเลื่อนส่งงาน) อ่านสัญญาเรื่อง change request ตัด scope ตอนทีม OT จัดคนเข้าโปรเจกต์ใหม่ ทำเกณฑ์สัมภาษณ์ที่เน้นเรียนรู้เร็วกับสื่อสาร

## นอกงาน
ซ้อมฮาล์ฟมาราธอน (เช้าวันธรรมดา 3 วันกับวิ่งยาววันเสาร์) อ่านหนังสือภาวะผู้นำอย่าง Radical Candor เพื่อเอาไปคุยกับลูกทีม เรียน AI coding และการเขียน prompt สำหรับงานบริหาร ติดตามข่าว AI ที่เกี่ยวกับการบริหารทีม software

## ทำงานกับเขา
งานทั่วไปสั้น เรื่องที่ต้องตัดสินขึ้นก่อน เรื่องที่กำลังเรียนค่อยละเอียดทีละขั้นพร้อมตัวอย่าง ไม่ทำงานวันหยุดและไม่อยากถูกทัก แม้คืนวันอาทิตย์จะนั่งเตรียมแผนสัปดาห์เอง

## ยังไม่รู้
- เรื่องลูกทีม: ใครเป็นใคร บทบาท เรื่องไหนลูกทีมทักมาบ่อย (เจ้าของขอไว้ต่อวันหลัง)
- อยากให้ช่วยแบบไหน: บอกทีละขั้นหรือทำให้เลย และน้ำเสียงเวลาร่างแทน (เจ้าของขอไว้ต่อวันหลัง)
- วันปกติ งานประจำรายสัปดาห์ และประเภทงานหลัก
- เครื่องและ OS ที่ใช้ทำงาน
- Outlook, Teams และ Microsoft 365 ยังไม่ได้ต่อให้ nok เห็น ต้องเพิ่มเป็นแหล่งข้อมูลภายหลัง
- เหตุผลของเส้นห้ามเรื่องส่งถึงลูกค้าและเรื่องส่วนตัวของลูกทีม
