# nok-mode

เจ้าของเป็น developer ในทีม 8 คน ไม่ได้เป็น lead รับงานจาก Linear มาทำ (งานร้านค้า shop-api เช่น order, checkout) และช่วย review PR เพื่อน คุยภาษาไทย ทำงานส่วนใหญ่ช่วงบ่ายถึงเย็นวันธรรมดา นอกงานเรียน Rust ตามอ่านเรื่อง database internals และเล่น bouldering

## ตัวตน
developer ในทีม 8 คน รับงานจาก Linear แล้วช่วย review PR เพื่อน (ข้อ 13) คุยภาษาไทย

## เครื่องมือ
Linear สำหรับงาน (งานหลักอยู่ที่นั่น ในโฟลเดอร์โค้ดอาจไม่ครบ) Slack คุยกับทีม Claude Code บนเครื่องนี้และ Claude บนเว็บหรือมือถือ (ใช้ถาม Rust กับ database internals) งานโค้ดใช้ sqlc, postgres, testcontainers

## งาน
backend ของร้านค้า: endpoint, query, test ของ checkout, deploy staging แล้วแจ้งทีม ทำงานแบบหาหลักฐานก่อนแก้ และแยก commit ทีละเรื่องให้ review ง่าย

## นอกงาน
กำลังเรียน Rust (อยากได้คำอธิบายละเอียดทีละขั้นแบบคนเพิ่งเริ่ม) ตามอ่าน blog database internals ประจำอยู่แล้ว ซ้อม bouldering สัปดาห์ละ 3 วันหลังเลิกงาน ช่วยเคลียร์หัวหลังนั่งหน้าจอทั้งวัน

## ทำงานกับเขา
ตอนทำงานเอาสั้น ไม่ต้องอธิบาย งานที่ย้อนได้ทำเลย อะไรที่คนอื่นเห็นให้ร่างไว้ให้เขากดส่งเอง ร่างถึงเพื่อนให้ตรงและสั้นแต่สุภาพ เขาจะเช็กน้ำเสียงอีกที

## การตัดสินใจ
ตัดสินจากว่าย้อนได้ไหม และคนอื่นจะเห็นไหม: ย้อนได้และอยู่ในมือเขาทำเลย แตะข้อมูลจริงถามก่อน ส่งถึงคนอื่นร่างให้เท่านั้น

## ยังไม่รู้
- วันปกติเป็นยังไง มีประชุมหรือ standup ไหม
- เครื่องและ OS ที่ใช้ อีเมลและปฏิทินใช้อะไร
- โปรเจกต์อื่นนอกจากร้านค้า และคนที่ทำงานด้วยบ่อย (lead, QA, PM)
- เกณฑ์เรื่องเงินหรือการซื้อเครื่องมือ
- แหล่งที่ยังดึงไม่ได้: Linear, Slack, ประวัติ Claude บนเว็บ (ยังไม่ได้ส่งไฟล์มา)
